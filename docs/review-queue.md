### D13 spec 的接口名怎么对应 design 里的网络

- 选了：**接口名 = 网络名**。`spec.interfaces[].name` 必须是 `design.json` 里某个网络的名字，对不上就在 G1 报
  `ir.spec_interface_net_missing`；负载 `between` 里写的网络、测量信号 `V(…)` / `I(…)` 里提到的网络、
  位号、引脚（`I(Q1.2)`）也都要在 design 里找得到，否则报 `ir.spec_signal_unknown`。
- 其他选项：每个接口再写一个 `net` 字段指定网络；接口直接写成连接器引脚（`J1.1`）；接口对应网络类。
- 理由：最简单，需求智能体少写一个字段，G1 一眼就能查；方案智能体起网络名时看着 spec 起就行。
  代价：接口名要符合网络名的规矩（不含空格和斜杠）；一个接口只能对应一个网络。
- 撤回：`Interface` 加 `net` 字段，`gates/ir_checks.py` 的 `check_spec_mapping` 改成查这个字段。

### D16 余量（margin）的定义，threshold 为 0 怎么办

- 选了：有符号的相对余量，`<=` 取 `(threshold − measured) / |threshold|`；`between` 下端按 `>=`、
  上端按 `<=` 各算一个，取较小的（离失败更近的一端）；**阈值为 0 时**：`pass.scale` 写了就拿它当分母，
  没写余量只表示方向（满足 +1，刚好 0，不满足 −1）。严格不等式刚好等于阈值时余量为 0 但判不通过
  （通过与否看比较结果，不看余量的符号）。写进了 PLAN §5.3，单测在 `tests/test_report.py`。
- 其他选项：阈值为 0 时用 |测量值| 当分母（结果永远是 ±1，没有量级信息）；余量取 None（排名时没法比）；
  统一用绝对余量（不同单位的余量没法放在一起）。
- 理由：0 阈值没有自然的量级，让写验收标准的人在需要时给出一个（`scale`）最诚实；不给也有确定的值。
- 撤回：`gates/report.py` 的 `margin()`。

### D17 `time_until` 的结果是「从 after 起算的时间间隔」

- 选了：结果 = 条件首次成立的时刻 − `after`（`after` 缺省 0，这时就是条件首次成立的时刻）。
- 其他选项：始终是绝对时刻。
- 理由：PLAN §5.1 的例子是 `after: "2ms"`、`pass: <= 0.001 s`（「在 1ms 内切断」），只有间隔的读法说得通。
  任务书写的「条件首次成立的时刻」在 `after` 缺省时与此一致。
- 撤回：`sim/testbench.py` 里 `time_until` 的拼法，以及 spec 里字段说明。

### D18 额定值检查怎么比

- 选了：`ratings` 的键按 `v…_max` / `i…_max` / `p…_max` 认电压 / 电流 / 功耗，别的键不查。
  电压比的是「网络对地电压」，不是器件两端压差：第一轮取器件各引脚所在网络里名字和 spec 接口同名的，
  取接口 `v_min` / `v_nom` / `v_max` 里**绝对值最大**的（不是只取标称，因为 3S/4S 锂电的标称 12.4 V，
  满电 16.8 V，按标称查会放过去）；第二轮用 G2 的 `device_stress` 峰值，电压再和第一轮的数取大的。
  不知道电压的网络不查。
- 其他选项：按引脚对算压差（`vds_max` ↔ D、S 脚），需要把键名和引脚名对上，键名没有统一写法；只取标称。
- 理由：单电源电路里对地电压大于等于压差，偏保守；双电源、浮地的电路会漏，到时候再换成按引脚对。
- 撤回：`gates/rules/ratings.py`。

### D19 去耦电容、悬空引脚、电源脚的判法

- 选了：
  - 去耦：对每个元件、每个接在「电源网络」上的电源输入脚（地脚和接地的负电源脚不算），这个网络上要有一个
    电容（`Device:C*` 系列）另一端接地网络；按拓扑，不看距离；两个电源网络之间的电容不算。
  - 电源脚：地脚（引脚名 GND、AGND、VSS……）必须接地网络；负电源脚（V−、VEE）接地或电源都行；
    其余电源输入脚必须接电源网络。「是不是电源 / 地网络」用原理图引擎的 `net_kind`，两边不会各说各的。
  - 悬空：只查符号库里电气类型是 `input` 和 `power_in` 的脚。
  - 两个输出：只算 `output` 和 `power_out`，开集、三态、双向不算冲突。
- 其他选项：悬空把双向脚也算；去耦要求每个电源脚各有一个电容。
- 理由：照任务书和 PLAN §7 的字面意思，用符号库已有的电气类型，不另造分类。
- 撤回：`gates/rules/` 下对应的文件。

### D20 封装可装配性只看封装名

- 选了：`min_package` 看封装名里的英制尺寸代码（`R_0805_2012Metric`），比规定的小就报错；
  `assembly = hand_solder` 时，名字里带 QFN、DFN、SON、LGA、BGA、WLCSP、CSP 的封装报错；
  `reflow`、`smt_service` 不限制。
- 其他选项：查封装库里的焊盘间距（手焊限制最小间距）；按封装的 3D 高度。
- 理由：简单、可单测；封装名里没有这些记号的，规则既不误报也不替它判断。
- 撤回：`gates/rules/assembly.py`。

### D21 G3 的网络电流取法，线宽检查的细节

- 选了：每个网络的电流 = max(spec 接口的 `i_max`，G2 仿真的这个网络电流上界)。上界取
  「各引脚电流绝对值之和的一半」在时间上的最大值——任何一段走线上的电流都不会超过它
  （把网络的引脚分成两边，穿过切口的电流等于一边的净流出，不超过两边绝对值和较小的那个）。
  没有电流数据的网络不查，只在 `counts.width_unchecked` 里计数。外层（F.Cu、B.Cu）和内层（In*.Cu）各按各的 k 值，
  取每层最窄的一段与最小线宽比；铜厚 35 µm、温升 10 °C 放在 `config.yaml` 的 `pcb:`。
- 其他选项：只用 spec 的 `i_max`；取单个引脚的最大电流（会漏掉多路汇合的网络）；忽略短于某长度的线段
  （布线器会在焊盘旁边把线收窄一小段）。
- 现状：`drc_checks` 有 `min_segment_mm` 参数，默认 0（都查）；等在真实布线结果上看过再定要不要忽略短段。
- 撤回：`gates/drc.py` 的 `estimate_net_currents`、`drc_checks`。

### D22 板尺寸可以转 90° 放

- 选了：把板子长边、短边分别和 `board_max_mm` 的长边、短边比，各超出各报一条。
- 其他选项：严格按宽 × 高比，不许转。
