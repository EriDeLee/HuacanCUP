# ADR-0010 embedding 模型推迟到 M4 再定

- 状态：已采纳（2026-10-31，用户决定）
- 影响：PLAN §9、§12 M0 待验证项④、§16

## 背景

PLAN 原定 M0 选定 embedding 模型，「本地 GPU 只跑向量模型」。实际情况：开发机的显卡是兆芯集成显卡（ZX C-1190），
不能跑这类模型；用户用的是云 GPU，向量模型最终只以一个 API 端口的形式提供给本系统。

## 决定

- M0 不选模型。到 M4（数据手册检索）时，用真实的数据手册做检索效果对比后再定模型和接口格式。
- 届时 `eda_agent/retrieval/` 只通过一个 HTTP 端口调用向量模型，地址、模型名写在 `config.yaml`，不写进代码。
