# ADR-0002 使用 KiCad 10.0.8（解压版）

- 状态：已采纳（2026-10-31，用户决定）
- 影响：PLAN §2「ERC/DRC/导出」、§16

## 决定

- 版本：KiCad 10.0.8（2026-10-30 发布）。9.x 最后一版是 9.0.9（2026-04-28），之后只给 10 出补丁。
- 来源：KiCad 官方下载页列出的清华镜像 `kicad-10.0.8-x86_64.exe`，969,079,176 字节；
  Authenticode 签名有效，签名者 `KICAD SERVICES CORPORATION`（GlobalSign EV 代码签名）。
- 安装方式：不运行安装程序，用 7-Zip 26.05 解压到 `.tools/kicad/`。
  7-Zip 本身也只解压：`7zr.exe` 解开 `7z2605-x64.exe`，两者 SHA-256 与 GitHub 公布的值一致
  （`9bf582b8…43b7`、`fd99e86f…47d0`）。

## 实测（KiCad 10.0.8，2026-10-31）

- `kicad-cli version` → `10.0.8`；对官方示例板 pic_programmer 跑 DRC（含原理图一致性）0 违规。
- 本项目用到的 kicad-cli 命令参数都按 `--help` 核对过：`sch erc`、`sch export netlist/svg/pdf`、
  `pcb drc`、`pcb export gerbers/drill/pos/step/glb`、`pcb render`。
- `--exit-code-violations` 打开时，有违规返回 5，报告照常写出。
- kicad-cli 没有 Specctra DSN 导出 / SES 导入命令（开发中的 11 才有），只能走 pcbnew 的 Python 接口，见 ADR-0004。
- 自带 Python 3.11.5，能 `import pcbnew`（10.0.8）。官方计划在 KiCad 11 删除这套 SWIG 接口，届时要改用 IPC API。
- `pcb export glb` 可用（PLAN §16 第 2 项）。
- 沙箱里的 KiCad 配置是全新的，没有库表，ERC 会对每个元件报「库不在当前配置」。
  `sandbox.py` 照 KiCad 首次启动的默认做法，复制 `share/kicad/template/` 里的 `sym-lib-table`、`fp-lib-table`。
